# Aura – Reverse Engineering Project

A recreation of the "Aura" accessibility landing page, made as an APL project.
I analysed the original app from a video, worked out how it behaves, and rebuilt it with Gemini.

## Features
- Persona selector (Voyager, Beacon, Guardian) that changes the colour theme
- "Simulate Aura Enforcer" mode that labels every element on the page
- "Clarify Content" toggle that simplifies the text and improves readability

## Tech
Plain HTML, CSS and JavaScript. No framework, no backend.

## Run
Open `index.html` in a browser.
